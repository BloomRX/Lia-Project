# UnoCSS na Lia
1. Confirme que a área usa UnoCSS e leia configuração, presets e atalhos efetivos.
2. Reutilize shortcuts, tokens, componentes e padrões existentes.
3. Agrupe classes de forma legível e consistente com os arquivos vizinhos. Não introduza attributify, presets ou transformers sem verificar configuração.
4. Preserve temas, foco, contraste, responsividade e movimento reduzido.
5. Não copie regras específicas do design system AIRI para outras superfícies da Lia.
6. Rode build/typecheck/testes relevantes e inspecione o resultado visual quando possível.
