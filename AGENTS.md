# Lia — instruções para agentes de pesquisa

Esta branch é uma **base documental leve**, não é a branch de implementação.

## Objetivo
Fornecer contexto suficiente para pesquisa, análise de produto, comparação de tecnologias e auditorias conceituais sem exigir checkout do código-fonte completo.

## Regras obrigatórias
1. Leia `README.md` e os documentos em `docs/` relevantes à tarefa.
2. Esta branch é somente leitura para sessões de agentes. Não tente editar, trocar de branch, renomear ou publicar nela.
3. Cada sessão Arena trabalha exclusivamente na branch vinculada à própria sessão. Não tente fazer checkout, push ou commit em outra branch.
4. Para pesquisa, registre descobertas, fontes, licenças, maturidade, limitações, riscos, compatibilidade com Windows/AMD e recomendação. Não implemente.
5. Para auditoria de código, solicite uma sessão criada a partir de `lia/development` ou receba um commit/patch específico. Não infira o estado do código a partir desta base documental.
6. Não presuma que o status aqui está atualizado. Confira o SHA de proveniência em `DOCS_VERSION` e peça atualização se a tarefa depender de estado posterior.
7. Não invente testes executados, compatibilidade, licenças ou resultados. Separe fatos confirmados, hipóteses e questões em aberto.
8. Não inclua segredos, tokens, credenciais, dados pessoais ou conteúdo privado nos relatórios.

## Entrega padrão
Produza um relatório Markdown com: resumo executivo; pergunta investigada; método e fontes; fatos verificados; opções comparadas; licenças/proveniência; riscos e limitações; recomendação; próximos passos; dúvidas não resolvidas.

## Idioma
Responda em português brasileiro, mantendo nomes técnicos e identificadores originais.
